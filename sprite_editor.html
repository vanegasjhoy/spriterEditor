Editor de sprites 8×8

Enciende píxeles en la cuadrícula y observa cómo se codifican como 64 bits, empaquetados en un valor hexadecimal de 16 dígitos.

Valor hexadecimal (16 dígitos)
0000000000000000
Cada clic hace un barrido de los 64 píxeles (1 = encendido, 0 = apagado) y convierte esa cadena binaria a hexadecimal. "Cargar Hex" hace el proceso inverso: expande el hex a binario de 64 bits y repinta la cuadrícula.
